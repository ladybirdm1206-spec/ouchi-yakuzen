# おうち薬膳・野菜アドバイザー

家庭にある食材から、手軽に健康ごはんのヒントが見つかる Web アプリです。
薬膳（中医学）の「五色」と「あたためる・冷ます（五性）」の考え方をもとに、やさしい言葉でガイドします。

## できること

- **食材から探す**：冷蔵庫にある食材を選ぶと、色のバランス・温冷バランス・おすすめメニュー・ちょい足し薬味を提案
- **体の調子から探す**：「冷えが気になる」「胃腸が重い」などの悩みから、おすすめの色と野菜、食べ方の工夫を提案
- **五色パレット**：緑・赤・黄・白・黒の食材と、体とのつながりがわかるミニ図鑑

## 使い方

`index.html` をブラウザで開くだけで動きます（外部ライブラリなし）。

GitHub Pages で公開すると、スマホの「ホーム画面に追加」で土鍋アイコンのアプリとして使えます。

## ファイル構成

```
index.html          アプリ本体（HTML・CSS・JavaScript）
manifest.json       ホーム画面に追加したときの設定
icons/              アイコン（SVG と PNG）
```
